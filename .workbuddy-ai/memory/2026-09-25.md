- **Backend `models.go`**: Added `Prodi` model (Code, Name). Added `ProdiID` + `Prodi` relation to both `CPL` and `Course` structs.
- **Backend `db.go`**: AutoMigrate includes `Prodi`. Seeds 8 program studi on first run: PSEJ, PMAT, PBSI, PBI, PJKR, PIN, PGSD, PPG.
- **Backend `academic.go`**: New `ListProdi` handler. `ListCPL` now filters by `?prodi_id=` query param and preloads `Prodi`. `CreateCPL`/`UpdateCPL` accept `ProdiID`. `ListCourses`/`GetCourse`/`CreateCourse`/`UpdateCourse` preload `Prodi` and support `?prodi_id=` filter.
- **Backend `router.go`**: New route `GET /api/prodi`.
- **Frontend `AdminCPL.jsx`**: Prodi filter chips, prodi selector in Create dialog, CPL cards grouped by prodi with prodi badge.
- **Frontend `Courses.jsx`**: Prodi filter chips, prodi selector in Create dialog, prodi badge on course cards.
- **Frontend `ObeTab.jsx`**: Accepts `course` prop, filters CPL by `course.prodi_id` so only relevant CPLs appear when linking CPMK→CPL.
- **Frontend `CourseDetail.jsx`**: Passes `course` to `ObeTab`.
- **Frontend `printRps.js`**: RPS print identitas table now shows the course's prodi name dynamically instead of hardcoded "Informatika".
